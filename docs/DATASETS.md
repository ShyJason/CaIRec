# Dataset sources

CaIRec does not redistribute third-party interactions, product images, text,
or extracted content features. Download these materials from their upstream
sources and comply with the terms stated by those sources.

## Clothing and Sports

Use the processed Amazon datasets linked by
[MMRec](https://github.com/enoche/MMRec) and
[I3-MRec](https://github.com/HuilinChenJN/I3-MRec):

<https://drive.google.com/drive/folders/13cBy1EA_saTUuXxVllKgtfci2A09jyaG?usp=sharing>

Copy the downloaded directories to:

```text
Data/
├── clothing/
│   ├── clothing.inter
│   ├── image_feat.npy
│   ├── text_feat.npy
│   ├── train.txt
│   ├── val.txt
│   ├── test.txt
│   ├── u_id_mapping.csv
│   └── i_id_mapping.csv
└── sports/
    └── (the corresponding sports files)
```

## Beauty

The Beauty data used in this project was prepared locally. It was not
downloaded as a processed MMRec bundle. Its two raw inputs are from the 2014
Amazon Product Data release by Julian McAuley:

- `reviews_Beauty_5.json.gz`:
  <https://snap.stanford.edu/data/amazon/productGraph/categoryFiles/reviews_Beauty_5.json.gz>
- `meta_Beauty.json.gz`:
  <https://snap.stanford.edu/data/amazon/productGraph/categoryFiles/meta_Beauty.json.gz>

Do not substitute the 2018 `All Beauty` release: it is a different dataset.
Verify the two raw files before preprocessing:

```text
e5925ec99023f1dc9c7d3dff7ef34cfeacd40d1b981b5525e1e4ba9c8abc18fe  reviews_Beauty_5.json.gz
c7977dc0e0ead14ac7df8c1c6de74da00e4bebfad87a0f0c5763d4c5bc9b53a0  meta_Beauty.json.gz
```

Install the additional preprocessing dependencies in a separate environment
if desired:

```bash
python3.10 -m venv .venv-beauty
. .venv-beauty/bin/activate
python -m pip install -r requirements-beauty.txt
```

Place both raw files in a directory, then run:

```bash
python scripts/prepare_amazon_beauty.py \
  --source-dir /path/to/beauty-raw \
  --target-dir Data/beauty \
  --device cuda:0
```

The preparation procedure:

1. keeps metadata entries having both a description and `imUrl`;
2. downloads each product image from the URL in Amazon metadata;
3. deduplicates user-item reviews by retaining the latest timestamp;
4. retains users with at least three available interactions;
5. performs a per-user chronological leave-two-out split;
6. extracts 384-dimensional text features with
   `sentence-transformers/all-MiniLM-L6-v2`;
7. extracts 4096-dimensional image features with torchvision VGG16 default
   weights, before its final classifier layer.

Expected dataset statistics are:

```json
{
  "users": 21752,
  "items": 11161,
  "interactions": 165325,
  "splits": {"train": 121821, "val": 21752, "test": 21752},
  "image_feature_shape": [11161, 4096],
  "text_feature_shape": [11161, 384]
}
```

## CaIRec missing payloads

After installing the data, fetch CaIRec's small, pre-generated 50% missing-item
payloads:

```bash
python scripts/download_assets.py --payloads all
```

The downloader verifies the release archive and installs one payload in each
dataset directory. These files are generated by CaIRec and are separate from
the upstream datasets.
